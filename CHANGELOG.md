## [0.1.0] - 2026-09-18

First release.

- `jevi ask` sends a text plus typed questions to TypeSafe's Jev and prints a verdict per
  question: yes/no for a `noul`, the chosen option for a `choice`, the level for a `score`.
  Several questions ride in one request.
- **`unsure` is a first-class verdict with its own exit code (3).** Jev's probability is
  trustworthy at the extremes and not in the middle, so a two-way classifier would have to
  call an untrustworthy region something and both answers would be wrong.
- **Exit 2 is reserved and never emitted**, including for a mistyped flag, because a hook's
  exit 2 means "block this tool call" to Claude Code.
- **Thresholds live in the question set with their provenance**, and `validated.model` and
  `validated.max_chars` are enforced on every call: answer from a different model, or a
  state longer than the one measured, and the verdict is forced to `unsure` saying which
  rule forced it. Without a `validated` block every answer is marked `thresholds: default`.
- `--soft` never fails loudly: no key, no network, an API error, all become exit 0 with the
  reason on stdout, so a hook is never broken by this binary.
- Two providers, OpenRouter and TypeSafe direct, chosen by whichever credential is present.
  The OpenRouter shape is verified against real traffic; the direct one is written from the
  documentation and not yet exercised.
- No `guard` verb, deliberately: Jev is steerable by the text it judges, so it is not a
  security boundary.
